# Projeto de Análise de Vendas com Python

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar os fundamentos da linguagem Python por meio da análise de dados de vendas de produtos fictícios.

O programa lê os dados de um arquivo CSV, calcula indicadores de vendas e apresenta os resultados no terminal.

## Tecnologias utilizadas

- Python
- Arquivo CSV
- Visual Studio Code (VS Code)
- Biblioteca padrão `csv`

## Funcionalidades

- Leitura de dados de vendas a partir de um arquivo CSV.
- Cálculo do faturamento por produto.
- Cálculo do faturamento total e da quantidade total vendida.
- Identificação dos produtos com maior e menor faturamento.
- Classificação dos produtos por faturamento.
- Cálculo do percentual de participação de cada produto no faturamento total.
- Cálculo do faturamento médio por produto.
- Validação de dados inválidos e tratamento de erros.

## Estrutura do projeto

- `ler_vendas.py`: código Python responsável pela análise das vendas.
- `vendas.csv`: arquivo com os dados dos produtos, quantidades e preços.
- `README.md`: documentação do projeto.

## Como executar

1. Instale o Python.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no VS Code.
4. Execute o arquivo `ler_vendas.py`.

## Aprendizados

Durante o desenvolvimento, pratiquei leitura de arquivos CSV, variáveis, estruturas condicionais, laços de repetição, funções, tratamento de erros, cálculos e organização de dados.

Este projeto faz parte da minha jornada de aprendizado em Python e Análise de Dados.
